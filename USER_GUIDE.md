# Thousand Hills Vacations - Show Schedule Creator

## User Guide for Sales Reps

Transform your plain show schedule PDFs into beautifully branded Thousand Hills Vacations documents.

---

## Getting Started

### First Time Setup (Mac)

1. **Copy the app** to your Applications folder or Desktop
2. **Right-click** the app icon
3. Click **"Open"**
4. Click **"Open"** again when macOS asks for confirmation

After the first time, just double-click to open!

### First Time Setup (Windows)

1. **Copy the .exe file** to your Desktop or Documents
2. **Double-click** to run
3. If you see a security warning:
   - Click **"More info"**
   - Click **"Run anyway"**

After the first time, no more warnings!

---

## Using the App

### Step 1: Start the Application

**Mac:** Double-click `ThousandHillsScheduleCreator.app`

**Windows:** Double-click `ThousandHillsScheduleCreator.exe`

Your web browser will open automatically!

### Step 2: Upload Your PDF

You have two options:

**Option A:** Drag and drop your PDF file onto the upload area

**Option B:** Click "Choose File" and select your PDF

### Step 3: Wait for Processing

The app will:
- Read your show schedule
- Apply Thousand Hills branding
- Create a beautiful new PDF

This usually takes just a few seconds!

### Step 4: Download Your Branded PDF

Click **"Download PDF"** to save your new file.

You can also click **"Preview"** to view it first.

### Step 5: Create Another (Optional)

Click **"Create Another"** to brand more schedules.

---

## Tips

- **Keep the window open:** Don't close the black terminal window (it runs the app)
- **File size limit:** PDFs must be under 16MB
- **File format:** Only PDF files are supported
- **Where files go:** Downloads go to your usual Downloads folder

## Troubleshooting

### Browser doesn't open automatically

Manually open your browser and go to:
```
http://127.0.0.1:5000
```

### "Upload failed" error

- Check that your file is a PDF
- Make sure file is under 16MB
- Try closing and reopening the app

### App won't start on Mac

If you get "App can't be opened":
1. Right-click the app
2. Click "Open" (not double-click)
3. Click "Open" in the dialog

### App won't start on Windows

If you get security warning:
1. Click "More info"
2. Click "Run anyway"

### Nothing happens when I upload

- Check that you selected a PDF file
- Make sure the app window is still running
- Try refreshing your browser
